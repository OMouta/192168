Fake LANs
for real friends.

192168 puts you and your friends on the same LAN from different networks, so you can play LAN games together. Everyone who connects gets an address like 10.69.0.2, and any game that lets you type in a host address works from there.

Getting started

  1. 01

    Create a group

    Give it a name and a password. That is the setup.

  2. 02

    Send both to your friends

    They join once. After that, connecting is one click.

  3. 03

    Play

    The app lists who is online and the address each of them got. Give one to the game as the host.

How it works

Traffic goes straight between players

Two machines find a route to each other and send game packets over UDP, encrypted with the Noise protocol. Nothing relays them.

The server only introduces you

It hands out the addresses and says who is online. Game packets never reach it, and a session that is already up survives it going down.

Point it somewhere else

Type another server's URL into Settings and the app uses that one. Running your own is a container and a database.

Read the code

The client, the daemon and the server are all on GitHub under MIT.

Groups

A group sticks around.

You join with its name and password once, and after that the app remembers you. Belong to as many groups as you like. One of them can be connected at a time.
